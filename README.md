### 🧠 ML Capabilities

- **Classical ML** — regression, tree ensembles, SVM, KNN, clustering, PCA, gradient boosting, cross-validation and hyperparameter search
- **Deep Learning** — MLPs, CNNs and transfer learning; custom PyTorch training loops written from scratch
- **Transformers & NLP** — tokenization, attention, encoder/decoder architectures; a mini-GPT built from scratch
- **LLM Fine-tuning** — PEFT, LoRA / QLoRA (incl. a from-scratch LoRA layer), DoRA, quantization with GPTQ, AWQ and GGUF
- **RAG** — embeddings, chunking, reranking and vector search with pgvector, Qdrant and Chroma
- **Agents** — agent loops, tool calling, MCP and A2A protocols
- **MLOps** — FastAPI inference services, Docker, MLflow model registry, experiment tracking, drift monitoring and CI/CD
